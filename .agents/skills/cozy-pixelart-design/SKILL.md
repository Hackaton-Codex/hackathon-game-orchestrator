# Cozy top-down pixel-art design

Create a consistent, original pixel-art vocabulary for small game worlds. This skill describes the broad, welcoming top-down pixel-art direction associated with cozy life-simulation games; it does not reproduce any particular game's characters, tiles, layouts, or distinctive assets.

## Workflow

1. Identify the target canvas size, intended display size, camera angle, and whether the work is a tile set, character, prop, or full scene. If unknown, state a practical assumption before producing the asset.
2. Set a pixel scale and keep edges, outlines, clusters, and detail density consistent across assets that share a scene.
3. Use a limited, coordinated palette with warm earth tones and readable accents. Reserve the brightest or most saturated colors for focal points and interactions.
4. Build scenes from clear ground, path, vegetation, structure, and foreground layers. Keep routes and interactable objects legible at the actual in-game size.
5. Give each asset a simple silhouette and use deliberate pixel clusters. Avoid noisy single-pixel texture, unintended anti-aliasing, and detail that disappears when scaled down.
6. Review the result at native resolution and at its expected display size. Check contrast, tile seams, silhouette readability, and consistency with neighboring assets.

## Constraints

- Treat named games as broad genre references only; create original compositions, characters, palettes, and tile arrangements.
- Do not call painterly high-resolution art “low-resolution pixel art” just because it has pixel-like texture. Describe the actual technique and recommend a fitting pipeline.
- Preserve the project's established camera and palette unless the user asks to change direction.
- For assets with external sources, retain the source, author, license, and modifications for the project's resource audit.
