# Caso de estudio: Maite: Rumbo al Salar

**Estado:** prueba de skills y creación de un juego web. No hay certeza de que el proyecto se retome.

Esta carpeta guarda resultados de evaluación que ayudan a ver qué funcionó y qué conviene mejorar. No es una especificación para la hackatón: el equipo puede elegir otro género, historia, estilo y tecnología. El código y los assets originales de Maite permanecen fuera de este repositorio.

## Resultados

- [Cantera chilena: pixel art, escena 2.5D y transición de mapa](cantera-chile/README.md)
- [Arte del personaje: retratos, sprites y movimiento](character-art/README.md)
- [Pruebas de narrativa y balance](narrative-balance/README.md)
- [Puzles: revisión de turnos y referencias de diseño](puzzles/referencias-mecanicas.md)

## Límites de las pruebas

- Las imágenes son previsualizaciones JPG comprimidas. No se publicaron los PNG originales.
- Los resultados visuales son conceptos, no assets aprobados para producción.
- La prueba del mapa no ejecuta colisiones ni valida rutas en el juego.
- La revisión de puzles fue estática; el recorrido interactivo sigue pendiente.
- Las evaluaciones de narrativa y balance no sustituyen un playtest de la partida completa.

## Si se retoma Maite

Trata este material como historial de pruebas. Revisa el código y los assets activos de la versión vigente antes de reutilizar decisiones; confirma qué partes siguen siendo válidas con el equipo.
